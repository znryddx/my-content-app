# 工位图片目录（替换 SVG 工位用）

把每个板块的真实图片放在这个目录，**按文件名覆盖即可自动生效**（代码：有图优先用图，没图才用 SVG 兜底）。

## 文件名 = 板块中文名 + .png
- `手串.png`   → 手串
- `沉香.png`   → 沉香
- `香道.png`   → 香道
- `香炉.png`   → 香炉
- `造像.png`   → 造像
- `百宝嵌.png` → 百宝嵌
- `茶空间.png` → 茶空间
- `高端礼品.png` → 高端礼品
- `简报.png`   → 简报

图片建议：透明背景 PNG，尺寸约 600×660（与工位卡比例接近），正面平视的 Marvis 工位风格。
